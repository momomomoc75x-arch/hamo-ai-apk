# HAMO AI Portable v1

## ما الذي يعمل الآن؟
- واجهة عربية زرقاء تعمل محلياً في المتصفح.
- أوامر تجريبية بسيطة دون إنترنت.
- حفظ ملاحظات مؤقتاً أثناء الجلسة.
- تصدير واستيراد الذاكرة بصيغة JSON لنقلها إلى الفلاشة.

## تشغيل Windows
1. افتح `index.html` في Edge أو Chrome.
2. لا يحتاج إلى تثبيت برنامج إضافي.
3. استخدم «تصدير الذاكرة» واحفظ `hamo-memory.json` داخل مجلد `DATA` على الفلاشة.

## تشغيل Android
1. ثبّت APK من مخرجات GitHub Actions باسم `Hamo-AI-APK`.
2. شغّل Ollama على الكمبيوتر وتأكد أن `ollama list` يعرض `qwen2.5:7b`.
3. من `D:\HamoAI\project\hamo-server` شغّل `npm start`.
4. وصّل الهاتف والكمبيوتر بنفس شبكة Wi-Fi. عنوان الكمبيوتر الحالي `http://192.168.1.3:3000` ويمكن تغييره من التطبيق.
5. اسمح باتصالات TCP الواردة على المنفذ 3000 ضمن شبكة Private فقط، ثم اضغط «اختبار» في التطبيق.
6. للاتصال من محاكي Android استخدم العنوان `http://10.0.2.2:3000`.

الـAPK لا يحتوي أوزان النموذج؛ Qwen يعمل على الكمبيوتر عبر Ollama، ويجب أن يبقى الكمبيوتر والسيرفر شغالين أثناء استخدام التطبيق.

## حدود النسخة الأولى
- المحادثة الذكية تحتاج اتصال التطبيق بسيرفر الكمبيوتر؛ الأوامر البسيطة تعمل محلياً.
- لا ترسل رسائل واتساب تلقائياً. فتح واتساب لا يعني الإرسال.
- خادم حمو يتصل بـOllama على الكمبيوتر محلياً ولا يحتاج مفتاح خدمة سحابية.
- لا تحفظ كلمات مرور أو بيانات حساسة في هذه النسخة.

## حفظ الملفات على D
- نسخة المشروع: `D:\HamoAI\project`
- نسخة بيانات نماذج Ollama: `D:\HamoAI\models`
- يرفع GitHub Actions ملف APK الناتج كـartifact على فرع التطوير.
