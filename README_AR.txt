# HAMO AI Portable v1

## ما الذي يعمل الآن؟
- واجهة عربية زرقاء تعمل محلياً في المتصفح.
- أوامر تجريبية بسيطة دون إنترنت.
- حفظ ملاحظات مؤقتاً أثناء الجلسة.
- تصدير واستيراد الذاكرة بصيغة JSON لنقلها إلى الفلاشة.

## تشغيل Windows
1. افتح `index.html` في Edge أو Chrome.
2. لا يحتاج إلى تثبيت برنامج إضافي.
3. استخدم «تصدير الذاكرة» واحفظ `hamo-memory.json` داخل مجلد `DATA` على الفلاشة.

## تشغيل Android
1. وصل الفلاشة باستخدام وصلة USB OTG.
2. افتح `index.html` من مدير الملفات باستخدام متصفح يدعم فتح الملفات المحلية.
3. إذا منع المتصفح فتح الملف، انسخ مجلد المشروع مؤقتاً إلى الهاتف وافتح `index.html` منه.
4. استورد ملف الذاكرة من الفلاشة عند الحاجة، ثم صدّر النسخة المعدلة إليها.

## حدود النسخة الأولى
- هذه نسخة واجهة أولية وليست نموذج ذكاء اصطناعي كامل.
- لا تحتوي على APK أو EXE أصليين بعد؛ `index.html` تطبيق ويب محمول.
- لا ترسل رسائل واتساب تلقائياً. فتح واتساب لا يعني الإرسال.
- وضع Hybrid في هذه النسخة مجرد اختيار واجهة؛ ربط مزود ذكاء اصطناعي يحتاج خادماً/واجهة API ومفتاحاً لا يوضع داخل ملفات عامة على الفلاشة.
- لا تحفظ كلمات مرور أو بيانات حساسة في هذه النسخة.

## خطة النسخة التالية
1. بناء تطبيق Windows مستقل.
2. بناء تطبيق Android APK.
3. ربط ذاكرة مشتركة آمنة على USB.
4. إضافة نموذج محلي مناسب لموارد الأجهزة أو ربط API اختياري.
5. إضافة أدوات تنفيذ منفصلة بصلاحيات واضحة وموافقة المستخدم.
